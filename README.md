# AWS projects
## Repositories for all things AWS-related.

## [Setup an IAM user group for administrators, without using the root account](./Admin_group_no_root.md)
How to setup an IAM user group where the users login as standard users and can then promote themselves to an 'Administrator' level session. This protects the root user account as it is not required. It also improves event tracking and administering just which users have admin-level access.
